This project is a sophisticated, full-stack web application engineered for real-time traffic sign recognition. At its core, the system utilizes a Deep Learning model trained on the German Traffic Sign Recognition Benchmark (GTSRB) dataset. The backend is powered by a high-performance FastAPI server that loads the pre-trained TensorFlow .h5 model to handle inference. When a visual payload is received, the backend intelligently isolates and auto-crops the traffic sign from noisy backgrounds, standardizes the image format, and swiftly categorizes the input into one of 43 different specific classes—ranging from speed limits to hazard warnings—in a matter of milliseconds.

The frontend is a sleek, ultra-responsive dashboard built using React and Vite that rivals professional enterprise interfaces. Instead of relying on manual image uploads, it taps securely into the user's webcam and captures frames on a continuous automatic loop, creating a frictionless user experience. Designed with premium dark-slate aesthetics, dynamic floating SVG background animations, and live confidence/status indicators, the application transforms a simple Artificial Intelligence model into an immersive "intelligent vehicle dashboard" that flawlessly bridges the gap between machine learning and an interactive user experience.
